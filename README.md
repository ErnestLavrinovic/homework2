# Receptų programėlė

Antra praktinė užduotis. Programėlėje galima peržiūrėti receptus pagal kategorijas ir išsisaugoti pastabas prie receptų.

## Kaip paleisti naujame kompiuteryje

1. Įsidiegti Node.js (kartu įsidiegia npm) ir Git.
2. Telefone įsidiegti su projektu suderinamą Expo Go.
3. Atsisiųsti projektą ir atsidaryti jo aplanką terminale:

```sh
git clone https://github.com/ErnestLavrinovic/homework2.git
cd homework2
```

4. Įdiegti projekto paketus:

```sh
npm ci
```

5. Paleisti projektą:

```sh
npm start
```
